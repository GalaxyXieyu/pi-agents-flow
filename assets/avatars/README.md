# Fleet Pixel Avatars

These 16 PNG avatars are deterministic samples generated from DiceBear's `pixel-art` style.

- Style: Pixel Art by DiceBear
- Source: https://www.dicebear.com/styles/pixel-art/
- Style license: CC0 1.0
- License: https://creativecommons.org/publicdomain/zero/1.0/
- Generation: DiceBear HTTP API 9.x, fixed seeds, 192 px PNG, circular white background

The runtime uses these local files and does not call the DiceBear API. Agent identity keys deterministically select one asset; the selected asset stays the same across localized display names.
