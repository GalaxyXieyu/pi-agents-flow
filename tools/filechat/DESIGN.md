# filechat 实现规约（DESIGN）

本文档定义 `filechat` 命令行工具的简明实现规约，供实现阶段直接编码。本工具为纯标准库实现，不含第三方依赖。

## 1. 目标

`filechat` 是一个独立的 Python 命令行工具，读取一个文本文件，按行拆分并统计：

- 总行数
- 非空行数
- 单词总数
- 最长行长度
- Top 5 高频词

输出一份易读的文本报告。

## 2. 命令行用法（CLI）

单一入口脚本，建议文件布局：

```
tools/filechat/
├── filechat.py        # 入口脚本（argparse + 主流程）
├── analyzer.py        # 统计逻辑（纯函数，便于测试）
├── tests/
│   └── test_analyzer.py
└── README.md
```

### 2.1 调用形式

```
python3 filechat.py <文件路径>
python3 filechat.py [选项] <文件路径>
```

### 2.2 参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `<文件路径>` | positional | 是 | 要分析的文本文件路径 |
| `--top N` | int | 否 | 高频词条数，默认 `5`，取值范围 `1 ≤ N` |
| `--encoding ENC` | str | 否 | 指定读取编码，默认 `utf-8` |
| `--help` / `-h` | flag | 否 | 打印帮助并退出 |

### 2.3 退出码约定

| 退出码 | 含义 |
|---|---|
| `0` | 分析成功 |
| `1` | 文件不存在 / 不可读 / 非 UTF-8 解码失败（或用户未覆盖编码） |
| `2` | 参数错误（由 argparse 兜底） |

## 3. 输入格式

- 输入：任意文本文件，按字节流读取，按指定或默认编码（`utf-8`）解码为 str。
- 行拆分：使用通用换行符语义（统一处理 `\n`、`\r\n`、`\r`），不保留行尾换行符计入行内容。
- 空行定义：去掉首尾空白后长度为 0 的行为空行。
- 单词定义：按空白字符（空格、Tab、换行等）切分的 token。仅统计非空 token。大小写不折叠（`Hello` 与 `hello` 视为不同词）。
- 最长行长度：取所有行（含空行）中去掉换行符后的字符数最大值；空文件下无最长行。

## 4. 输出格式

输出为易读文本报告，使用简体中文标签，示例：

```
文件: example.txt
总行数: 12
非空行数: 10
单词总数: 87
最长行长度: 45

Top 5 高频词:
 1. the      (12 次)
 2. hello    (8 次)
 3. world    (5 次)
 4. python   (3 次)
 5. code     (2 次)
```

- 报告打印到 `stdout`。
- 高频词按出现次数降序；次数相同时按（出现顺序）或（字典序）稳定排序，规约固定为「次数降序、字典序升序」以保证可复现。
- 若词种不足 `--top N`，按实际词种数输出，不补充。

## 5. 边界情况（Edge Cases）

| 场景 | 行为 |
|---|---|
| 空文件 | 退出码 `0`；报告显示总行数 `0`、非空行数 `0`、单词总数 `0`、无最长行（标为 `N/A`）、无高频词 |
| 纯空行文件 | 总行数 ≥ 1，非空行数 `0`，单词总数 `0` |
| 非 UTF-8 文件 | 默认退出码 `1` 并报错；若用户传 `--encoding` 覆盖则按该编码尝试解码 |
| 单行超长 | 不作为错误；按实际字符数统计最长行长度，正常完成 |
| 文件不存在 / 不可读 | 退出码 `1`，向 `stderr` 输出错误信息 |
| `--top 0` 或负数 | 参数错误，退出码 `2` |
| 空白字符定义 | 使用 `str.split()` 语义，连续空白视为分隔符 |

## 6. 核心函数接口（供测试）

`analyzer.py` 暴露纯函数，便于单元测试：

- `count_lines(text: str) -> int`：总行数。
- `count_nonempty_lines(text: str) -> int`：非空行数。
- `count_words(text: str) -> int`：单词总数。
- `longest_line_length(text: str) -> int | None`：最长行长度，空文件返回 `None`。
- `top_words(text: str, n: int) -> list[tuple[str, int]]`：Top-n 高频词，`(词, 次数)` 列表。

## 7. 测试要求

- 使用标准库 `unittest`（或 `pytest` 兼容）编写 `tests/test_analyzer.py`。
- `python3 -m pytest` 可运行通过。
- 覆盖：空文件、纯空行、单行超长、非 UTF-8 解码失败、`--top` 合法性、高频词排序稳定性、（可选）CLI 退出码。
